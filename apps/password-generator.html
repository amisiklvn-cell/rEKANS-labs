About this app

Password Generator helps you create passwords using selected character types and adjustable length. It also includes password strength feedback and word-based passphrase generation.

Features

  • Adjustable password length.
  • Character type selection.
  • Password strength feedback.
  • Word-based passphrase generation.
  • Option to exclude similar characters such as O, 0, I, l and 1.
